# 💨 Technical Artist | Bridging Art and Technology

C++ 엔진 아키텍처와 그래픽스 파이프라인에 대한 이해를 바탕으로, 상호작용과 그래픽 표현의 한계를 확장하는 Technical Artist입니다

Unreal Engine C++, Technical VFX, Pipeline 기술을 융합하여 아티스트의 표현력을 극대화하고 게임의 퍼포먼스를 확보하는 데 집중합니다.

## 🚀 Technical R&D (기술 연구 및 진행 중인 프로젝트)
  
### 🏔️ C++ RDG & Compute Shader 기반 지형 변형 (진행 중 / CAVW SCIE 투고예정)
- UE5 C++ Render Dependency Graph(RDG) 패스 및 `.usf` Compute Shader 구축
- GPU Bit-packing 기반 VRAM 대역폭 절감 및 0.15ms 이하 실시간 Dynamic Mesh Deformation 달성
- Render Thread / RHI 병목 분석 및 RenderDoc, Unreal Insights 기반 프로파일링

### 💻 DirectX 11 + HLSL
- 그래픽스 파이프라인 매커니즘 이해를 위한 커스텀 C++ 렌더링 엔진 프레임워크 구축 (`ThorPrj`)
- PipeLine State Object(PSO) 제어 및 커스텀 HLSL Shader(VS/PS/CS) 구현

### 🛠️ Unreal Engine C++ Plugin & Editor Tooling
- Slate / Editor Subsystem 기반 커스텀 에디터 모듈 및 아티스트 전용 파라미터 제어 툴 R&D
- C++ Engine Tooling을 활용한 에셋 검증(Validation) 및 빌드 파이프라인 자동화

### 🪄 Houdini Engine & HDA Automation
- Houdini VEX 기반 절차적 메쉬 생성 및 UE5/Unity 연동용 Houdini Digital Asset(HDA) 제작
- 레벨 디자이너 및 아티스트용 절차적 렌더링/VFX 에셋 배치 파이프라인 구축

### 🐍 Blender Python DCC Pipeline
